# 查询结果变量

## 范围

运营分析的仪表盘和大屏可以把一次数据源查询的一列结果，当作后续参数的取值。参数引用的是整列，不拼接字符串。

这是通用能力。监控中心总览只是第一条配置：选择一个云区域和一条主机关联，查出该区域主机，再查出关联资产，再查出这些资产的监控实例和未恢复告警。

## 数据

- 仪表盘：`other.queryVariables`
- 大屏：`view_sets.queryVariables`
- 一条变量：`id`、`name`、`dataSource`、`params`、`valueField`
- 引用查询结果：`{ "queryRef": "<变量 id>" }`，可以是参数值，也可以嵌在条件里
- 引用已生效的筛选值：`{ "ref": "<筛选 id>" }`

变量链最多 3 级。循环、缺上游、上游为空或查询失败时，下游不发请求。空结果不能省掉列表参数，否则监控查询会变成查全部。

明细按页收集，每页 100 条，最多 20 页。计数查询不传页码。

## 这条大屏用到的查询

1. `query_cmdb_instances`：主机，`cloud` 等于所选云区域，取值 `inst_uuid`
2. `query_cmdb_one_hop`：起点是这些主机，关系由筛选选择，取值 `end_uuid`
3. `query_monitor_instances`：按 `cmdb_ids` 找监控实例，不指定监控对象
4. `query_monitor_alerts`：这些监控实例里状态为 `new` 的告警

字符串条件新增 `in`，编译成 `str[]`，用来把主机标识列表交给一跳查询。

监控实例查询新增 `cmdb_ids`。不填监控对象时必须填写它，并在当前用户可见的实例里查找。空列表返回空，不表示全部。
